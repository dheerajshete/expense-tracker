# Expense Tracker 💰

A simple and responsive expense tracker built with **HTML, CSS, and JavaScript**.

## Features

* Add expenses
* Enter expense name and amount
* Select an expense category
* Display added expenses
* Calculate total spending
* Delete individual expenses
* Save expenses using localStorage
* Restore expenses after refreshing the page
* Reset all expenses with confirmation
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter the expense name.
2. Enter the amount.
3. Select a category.
4. Add the expense.
5. View your expenses and total spending.
6. Delete expenses when needed.
7. Use **Reset** to remove all expenses.

Your expenses are stored in the browser using **localStorage**, so they remain available after refreshing the page.
